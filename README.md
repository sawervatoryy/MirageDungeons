# MirageDungeons
MirageDungeons добавляет на сервер сокровищницы - постройки со сундуками, появляются в случайных местах мира. Чтобы добраться до сундуков, игроки должны уничтожить блок привата (киркой или взрывом). После этого просыпаются стражи, а иногда и босс. Залутанные сокровищницы ночью исчезают, а мир возвращается в состояние, каким был до их появления.
